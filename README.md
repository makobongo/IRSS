## Intelligent Risk Survey System
###  Docker installation
Before you get started, ensure you have docker installed in your machine
````
[Download and Install Docker] (https://docs.docker.com/engine/install/)
````
### Project Setup
Clone the Repository
````
git clone [git@github.com:makobongo/IRSS.git](git@github.com:makobongo/IRSS.git)
cd IRSS
````
### Run the project:
````
docker compose up --build
````
### power the project down
````
docker compose down
````
